# cge_modeling

Instructions for coding agents working in this repository. Read this before changing anything.

cge_modeling builds, calibrates and simulates computable general equilibrium (CGE) models in Python. Models are
written as symbolic equations over named dimensions, compiled with PyTensor, and solved with the root finders in
`cge_modeling/solvers/`.

## Conventions

The human-facing guides are the source of truth. Read both before writing code:

- `docs/source/dev/index.rst` covers the environment, the pixi tasks, CI, tests and notebooks.
- `docs/source/dev/style_guide.rst` covers the conventions no tool enforces: design, naming, comments, numpydoc
  docstrings with an `Examples` section on every public entrypoint, tests and commit messages.

## Commands

```bash
pixi run test                    # the test suite; extra pytest arguments pass through
pixi run lint                    # every pre-commit hook on every file
pixi run -e docs docs-build      # build the docs with warnings as errors
```

## Layout

- `cge_modeling/base/` holds `CGEModel` and the symbolic primitives it is built from.
- `cge_modeling/compile/` turns a model's equations into compiled PyTensor functions.
- `cge_modeling/solvers/` holds the root finders.
- `cge_modeling/tools/` holds SAM estimation, output tables and other helpers.
- `tests/` mirrors the package layout.
- `notebooks/` holds the example gallery, which the docs read as `docs/source/examples/`.

## Rules that are easy to miss

- Execute a notebook top to bottom before committing it. The docs build does not execute notebooks, and a
  pre-commit hook rejects cells run out of order.
- A new public class or function needs an entry on its module's page under `docs/source/api/`.
- `conda_envs/environment_dev.yml` is generated by a pre-commit hook. Do not edit it by hand.
